## Local development

### Prerequisites

- Node.js 18+ (LTS recommended)
- npm 9+

### Setup

```bash
npm install
npm run dev    # http://localhost:3000
npm run build  # production build (required before deploy)
npm start      # serve production build locally
```

```

```

### Deploy to Vercel

Zero configuration required — push to GitHub and import in Vercel, or:

```bash
npx vercel
```

No environment variables, no database, no custom server. The app is fully static/client-side after build.
